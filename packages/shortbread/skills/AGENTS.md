## Cookie consent

This project uses Shortbread (https://tryshortbread.com) for GDPR cookie consent. The tag is `<script src="https://tryshortbread.com/shortbread.js" async></script>` in the document head (or `<ShortbreadConsent />` from `@shortbread/consent/react`). Scripts that set non-essential cookies are marked `type="text/plain" data-shortbread="statistics"` or `data-shortbread="marketing"` so Shortbread releases them after consent. Don't add a second banner or load analytics outside that gate. Docs: https://tryshortbread.com/llms.txt
